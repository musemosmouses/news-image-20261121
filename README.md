# The World in One Image — 21 November 2026

A program that draws a single newspaper front page summing up the world news of
Saturday 21 November 2026: 45 real stories, a UTC timeline and a date
check — drawn entirely in pure-stdlib Python, with no network at runtime.

Entry for the [make.fun bounty](https://make.fun/bounty/news-image-20261121)
"news-image-20261121" ($100, top 50 paid).

## Run

```sh
python3 main.py
```

`MAKEFUN_OUTPUT_DIR` sets the output directory (default `/output`).
The program writes `entry.png` there — 1024x1024, deterministic.
